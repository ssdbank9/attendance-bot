Attendance Bot

Connect to your GitHub repo to manage attendance from your phone

Security warning: this public GitHub Pages app receives a classic PAT with repo (full private-repository control) and workflow (run/update workflow) scope. The token is readable by scripts on this page, browser extensions, and anyone controlling this browser profile. It is kept only in this tab's session storage and expires here after 60 minutes. Use a short-lived token, select no additional scopes, never use a shared device, and clear it when finished.

How to get a token
  1. Go to github.com → Settings → Developer settings
  2. Personal access tokens → Tokens (classic)
  3. Generate new token (classic)
  4. Set the shortest practical GitHub expiration.
  5. Select only repo (required for this private repo's contents) and workflow (required for action buttons); select no other scopes.
  6. Copy the token and paste above
